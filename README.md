لوحة تحكم المأوى الآمن الذكي — نموذج أولي تفاعلي (3D) لمشروع BASTION، مسار المأوى الآمن.

- مخطط حي للطابق مع محاكاة سيناريو الحريق وعدّ الأشخاص
- نموذج 3D تفاعلي للمأوى قابل للتفكيك

> جميع البيانات محاكاة. هذا تصور مفاهيمي وليس نظامًا تشغيليًا معتمدًا.
